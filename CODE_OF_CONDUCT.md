# Code of Conduct

## Our pledge

We want participation in PandaAgent to be respectful, constructive, and
welcoming, regardless of background, identity, experience, or viewpoint.

## Expected behavior

- Discuss ideas and code in good faith.
- Give specific, actionable technical feedback.
- Respect differing experiences and accept correction when a mistake is made.
- Keep security reports and personal information private when appropriate.

## Unacceptable behavior

Harassment, threats, discrimination, personal attacks, doxxing, sexualized
language, and deliberate disruption are not acceptable.

## Enforcement

The maintainer may remove, edit, or reject contributions and interactions that
violate this code. Report concerns privately through the repository's security
reporting route or by asking the maintainer for a private contact channel.
